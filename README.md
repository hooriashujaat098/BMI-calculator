# BMI Calculator

A simple BMI Calculator built using **HTML, CSS, and JavaScript**.
This project calculates Body Mass Index based on user’s height and weight and shows the weight category.

## Features

* User inputs height and weight
* Calculates BMI instantly
* Displays BMI value
* Shows weight category
* Simple and clean user interface

## How It Works

1. User enters height in centimeters and weight in kilograms
2. Height is converted from centimeters to meters
3. BMI is calculated using the formula
   weight divided by height squared
4. The result is displayed
5. Based on the BMI value, the weight category is shown
